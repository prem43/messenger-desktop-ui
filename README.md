# Messenger Desktop UI

A messaging interface built with HTML, CSS and JavaScript.

## Setup

1. Install Node.js 22 or newer.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```bash
npm start
```

No dependency installation is needed.

## Development

Edit the files in `src/` and `css/`.

```bash
npm run build
npm run check
```

This project contains the frontend only. Messages and settings are saved in the browser; the backend is not connected.
